⚙️ Connect Supabase (Free, no card)

1. Create a free project

Go to supabase.com → Sign up → "New project". No credit card needed.

2. Create the loans table

Open the SQL Editor → paste this → click Run:

create table if not exists loans (
  id text primary key,
  customer_name text,
  email text,
  phone text,
  loan_name text,
  amount numeric,
  due_date text,
  status text default 'pending',
  currency text default 'GHC',
  created_at text,
  paid_at text,
  paystack_ref text
);
alter table loans enable row level security;
drop policy if exists "public access" on loans;
create policy "public access" on loans for all using (true) with check (true);

3. Get your API keys

Go to Settings → API → copy the Project URL and the anon public key.

4. Paste into this file

Open this HTML file in a text editor, find SUPABASE_URL and SUPABASE_ANON_KEY near the top of the script, paste your values, save, and re-upload.

💡 Supabase's free tier gives 500MB of database storage — more than enough for thousands of loans.
